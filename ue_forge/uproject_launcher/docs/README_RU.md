# UProject Launcher

UProject Launcher открывает Unreal Engine-проект с выбранными плагинами движка, включёнными только для запущенного процесса редактора. Дескриптор проекта не изменяется.

Параметры запуска расположены слева, список плагинов — справа. В небольшом окне параметры прокручиваются, а кнопки сохранения и запуска остаются видимыми под списком плагинов. Раскладка одинакова в отдельном launcher и в UE Forge.

Перетащите один файл `.ulaunch` на любую панель launcher, чтобы открыть профиль для редактирования. Если есть несохранённые изменения, перед открытием другого профиля появится подтверждение. Перетаскивание профиля не запускает Unreal Editor.

## Формат профиля

Профиль `.ulaunch` хранится в JSON:

```json
{
  "FileVersion": 1,
  "Project": "MyProject.uproject",
  "Engine": "C:/Program Files/Epic Games/UE_5.8",
  "Plugins": [
    {
      "Name": "MyLocalPlugin",
      "Enabled": true
    }
  ],
  "Arguments": "-log -NoSplash"
}
```

`Project` может быть абсолютным или относительным от профиля. Если поле отсутствует, используется соседний `.uproject` с таким же базовым именем. `Engine` принимает путь к корню движка или зарегистрированную версию. Кнопка автоматического определения заполняет оба поля по имени профиля и `EngineAssociation` проекта. Выключенные записи остаются в профиле, но не передаются Unreal Editor.

Для автоматического определения `EngineAssociation` проекта должен соответствовать зарегистрированному движку. Корень движка также можно указать вручную. Сканирование читает плагины из `Engine/Plugins` этого движка и поддерживает фильтр по названию, автору, версии и описанию.

Профиль считается локальными данными. Launcher не изменяет `.gitignore` и `.git/info/exclude`.

В настройках launcher откройте **Система** и нажмите **Зарегистрировать .ulaunch**. Двойной щелчок по профилю запускает проект. Классическое контекстное меню содержит **Запустить проект** и **Редактировать профиль**; в Windows 11 они доступны через **Показать дополнительные параметры**. Регистрация действует сразу для текущей учётной записи Windows и поддерживает UE Forge и отдельный launcher. После перемещения `.exe` выполните регистрацию заново.

Если Windows уже назначила другую программу для `.ulaunch`, нажмите **Приложения по умолчанию** и выберите **UE Forge UProject Launcher** для этого расширения. Регистрация сохраняет существующий выбор пользователя в Windows.

Отдельный launcher принимает путь к профилю или `--launch-profile <профиль>`. UE Forge также принимает `--launch-profile <профиль>`. Добавление `--open` открывает профиль для редактирования без запуска проекта.
